java.util.Queue:
================

FIFO - First In First Out

Queue is an interface which extends Collection interface

Queue is extended  by Deque interface.

Queue is directly implemented by PriorityQueue class.

LinkedList implements both List and Deque interface. 

Deque interrface is implemented by :
  - LinkedList
  - ArrayDeque classes
  
PriorityQueue:
==============
- implements Queue
- A PriorityQueue is a collection that stores elements according
  to their priority
- It will not process the lements based on the insertion order. 
- By default PriorityQueue gives priority to thge smalles t element.
- It does not maintain insertion order
- allows duplicates

Methods of PriorityQueue: 
 1. offer(e)  - inserts an element
    add(e) - inserts an element, throws exception if element cannot be
             inserted
    
 2. poll() - retrieve and remove the element with highest priority.
    remove()- removes the highest priority element
              but throws exception if the queue emption.
              
 3. peek() : returns the highest priority element .

DEQUE:
=====

Deque stands for Double Ended Queue
Collection->Queue->Deque

Deque is an interface which allows insertion, deletion and retrieval
of elements from both ends- front and rear

Normal queue follows FIFO
Deque can be used both as Queue(FIFO) and as a Stack(LIFO)

addFirst() - inserts an element at front
addLast()  - inserts an element at the rear

offerFirst()
offerLast()


To remove:
---------
removeFirst() 
removeLast()

pollFirst()
pollLast()

REtrieval: 
getFirst()
getLast()

peekFirst()
peekLast()


ArrayDeque:
==========
- internally uses resizable array
- does not allow null elements
- supports duplicate elements
- automatically grows when required
- It is efficient for insertion and deletion at both ends.
