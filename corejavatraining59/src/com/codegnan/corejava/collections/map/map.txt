Map - Key and value pair

In java Map is an interface 

Map belongs to java.util


Map:

- Map is an interface present in java.util package.
- Map will store the data in the form of Key and Value pairs
- Map can have multiple Key value pairs. 
- Each of these key and value pair is known as an Entry
- Group of these entries are known as EntrySet
- Set of all the keys in a Map are known as KeySet
- All the values are grouped together called as values.
- All the keys in a map must be unique
- Values can be duplicated. 
- Map interface will not extend Collection interface


HashMap: 

- belongs to java.util
- It implements Map interface
- It is a hashbased collection
-Methods in HashMap:
   
   - put()  - it adds a key,value pair in a map. 
   - get(key)  - get retrieves the value associated with a key.
               
   
   - keySet() - returns the keys as a Set from HashMap
   - values() - returns the values from the hashmap
   
Entry:
  Entry represents a Key and a value pair. 
  Entry is a inner interface of Map interface. 
  
  getKey(): getKey() is a method of Entry, it returns the key for an entry
  getValue(): it is a method of Entry, it returns the value for an entry.
